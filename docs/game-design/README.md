# Iva Games: «Тяга» и «Форпост»

Правила и карты: **0.1**. Порядок исполнения и запускающие задания: **0.2**, 28 ноября 2026 года.

Оценка владельца следует после самостоятельной приёмки исполнителя.

## Два разных игровых опыта

| | Тяга | Форпост |
|---|---|---|
| Жанр | Кооперативная физическая перевозка | Командный шутер со строительством и управлением машинами |
| Цель | Доставить физический груз через препятствия | Выиграть операции по доставке транспорта |
| Основные действия | Вести машину, крепить тросы, строить опоры, управлять механизмами | Целиться, стрелять, строить, управлять дронами, менять маршруты |
| Состав | 2–6 персонажей; от одного человека с ботом | Две равные команды по 1–3 места; люди и явно обозначенные боты |
| Пространство правил | Полный объём XYZ, Y вверх | Плоскость XZ, Y вверх; высота моделей не меняет стрельбу |
| Подача | Фиксированная ортографическая камера, объёмные материалы | Фиксированная ортографическая камера, читаемое поле боя |
| Художественная система | Светлая экспедиция, округлая техника, свой HUD и звук | Угловатая индустриальная тактика, собственные UI/материалы/звук |
| Результат | Общий для команды | Командная победа, поражение или ничья |

## Статус решений

Выбор игр и требования к результату принадлежат владельцу. Количества, стоимости, тайминги, карты, физика и интерфейс — проектные решения этой версии. Исполнитель реализует исходный профиль и проверяет заданными сценариями; изменения по наблюдениям оформляет новой версией параметров.

Основание: прочитанные исходники Iva Games на `357f60049e83b298bb5bbc2f760654fbd02384e3`. Факты о платформе и новые предложения разделены в сетевом контракте. Принятые игры и их сохранения сохраняются.

Проверка пакета касается документов; [выполненная сверка и её границы](VALIDATION.md) записаны отдельно. Игровые партии, баланс, производительность, ассеты и выпуск проверяются при реализации.
