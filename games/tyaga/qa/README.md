# Точный исходный реестр UI «Тяги»

`UI_ELEMENTS.json` — дополнение к `../UI_COVERAGE.md`. Это перечень фактических исходных элементов и способов ввода, полученный TypeScript AST из текущих файлов. Он **не запускает игру, не проверяет физику и не присваивает PASS**. Браузерная приёмка остаётся в `../ACCEPTANCE.md` и доказательствах соответствующей сборки.

## Воспроизведение

Из корня репозитория:

```sh
node scripts/tyaga-ui-inventory.mjs
node scripts/tyaga-ui-inventory.mjs --check
```

Можно задать отдельный путь `--out=path.json`. Генератор использует уже установленный `typescript`, не добавляет зависимости и не обращается к браузеру, серверу или базе. `--check` только сравнивает ожидаемый JSON с сохранённым и завершает работу с ошибкой, если реестр устарел. Перед общим commit его нужно повторно сформировать после изменения любого включённого файла, в том числе серверного `actions.ts` и плана `UI_COVERAGE.md`.

## Что считается элементом

Текущий снимок содержит:

| Категория | Количество исходных шаблонов / мест |
|---|---:|
| Native JSX controls | 123 |
| В том числе button / select / input / a | 97 / 15 / 6 / 2 |
| Native dialog / touch stick div / world-map svg | 1 / 1 / 1 |
| JSX canvas / details / summary / textarea | 0 / 0 / 0 / 0 |
| Вызовы общих компонентов и context provider | 39 |
| Пути монтирования от App | 186 |
| Нажимаемые области label, связанные с контролом | 21 |
| Шаблоны option | 31 |
| Canvas, созданные через WebGLRenderer | 2: один игровой интерактивный, один декоративный в меню |
| Imperative listeners / callback bindings / input lifecycle | 42 |
| Ветви обработки клавиатурных кодов | 19 |
| Серверные шаблоны `interactionsFor` | 24 |
| Группы исходного плана U01–U73 | 73 |

Эти числа **не являются количеством одновременно видимых DOM-узлов или количеством проверенных элементов**. Например, одна кнопка поручения повторяется для шести видов задач каждого существующего бота; один шаблон удаления бота повторяется по местам комнаты; один общий `Dialog` используется в нескольких независимых окнах. `sourceMountedControls` раскрывает конечный граф вызовов компонентов, сохраняя домены динамических повторов. Вариант миникарты `WorldMap` без `onMark` помечен как неинтерактивный: его открывает окружающая кнопка.

## Как читать JSON

- `sourceFiles`: размер, SHA-256 и Git blob SHA-1 **считанных байтов**, а не предположение о HEAD. Это связывает реестр с точным исходным содержимым даже до commit.
- `controls`: стабильный semantic ID, компонент, тег, исходные подписи RU/EN, атрибуты и обработчики. `disabled`, `aria-pressed`, `aria-expanded`, `value`, `checked`, `href`, `title` сохраняются настоящими выражениями.
- `componentInstances`: все вызовы компонентов, которые непосредственно или через потомков содержат управление. Props связывают общий шаблон с конкретными `onAction`, `onClose`, `label` и условиями.
- `sourceMountedControls`: ID шаблона плюс путь вызовов, унаследованные условия и домены повторов. Это позволяет отдельно адресовать кнопку закрытия настроек из главной и из игрового меню.
- `labelActivationAreas`: внешние и оборачивающие `<label>`, включая область нажатия checkbox/range. Каждый label связан с исходным контролом.
- `imperativeCanvases` и `imperativeControls`: создание canvas, его accessibility-атрибуты, pointer/wheel/context-loss listeners, callback Game→Scene, глобальная клавиатура, lifecycle нейтрализации ввода и непрерывная выборка управления.
- `domains`: все четыре карты в словаре (три маршрута и обучение), начальное оборудование карт, пределы мест 2…6, RU/EN названия тел, шесть поручений ботов, группы целевых действий, полный union `TyagaAction` и серверные шаблоны доступных действий.
- `coverageGroups`: существующие U01–U73 со статусами, **скопированными дословно**, без повышения их достоверности. `requiredRuntimeStates` перечисляет необходимый набор состояний; сам реестр их не проверяет.

Для адреса реального повторяемого элемента при QA дописываются ID существующего участника, предмета, socket, связи, комнаты или друга. Их нельзя выдумывать или заменять индексом при проверке идентичности. Все конечные исходные варианты — например, три карточки карт, шесть значений числа ботов и четыре сочетания двух голов и двух рюкзаков — следуют из options/повторов и props.

Исходные RU/EN выражения не равны вычисленному браузером accessible name. `conditions` отражает лексические ветви, но не доказывает достижимость состояния и не разворачивает произвольные предшествующие early returns. Прямые `actionTypes` не заменяют анализ динамической передачи действий через props. Для этих случаев сохранены определения обработчиков, исходные диапазоны и словари.

## Границы

Включён собственный клиент «Тяги», его поставщик динамических действий и источники конечных доменов. Ссылки на `/games`, `/friends` и переход на login присутствуют, но общие страницы портала не выданы за просканированные. Для полного U65 требуется отдельный реестр общего портала и фактическая проверка публичной сборки. Реестр также не является проверкой touch на физическом устройстве, производительности или реальной совместной партии.

При следующей сборке сначала выполнить `--check` после окончательного source freeze. Фактический buildId/artifactHash должен записываться в журнал приёмки, а не в этот независимый от сборки список.

## U65: отдельная граница общего портала

`PORTAL_ENTRY_ELEMENTS.json` формируется отдельно, без изменения основного
реестра игры:

```sh
node scripts/tyaga-portal-inventory.mjs
node scripts/tyaga-portal-inventory.mjs --check
```

Включены точные текущие исходники входа по почте и альтернативы Telegram,
языка/header/nav, загрузки и сообщений, карточки/preview «Тяги», списка комнат
и history clear/restore, общих полей создания комнаты, двух ссылок realtime
RoomDetail и перехода на Friends с возвратом через общую навигацию. Снимок
содержит **48 native control templates, 29 component instances, 67 mounted
source paths и 10 label activation areas** из 26 выбранных AST-областей.
Это количества исходных шаблонов, а не одновременно видимых элементов.

Каждый файл имеет SHA-256 и Git blob SHA-1 считанных байтов; каждый элемент —
компонент, источник, подписи/выражения RU/EN, обработчики, атрибуты,
лексические условия и домены повторов. `reviewScopeConditions` ограничивает
наш просмотр «Тягой» и не выдаётся за дополнительные условия в коде.
`mountedControls.instancePath` связывает общий PortalLink/Modal/Brand с его
конкретными props. `sourceEffects` сохраняет исходную смену языка, route/focus/
visibility refresh и установку/возврат фокуса Modal. Все элементы и состояния имеют **NOT_TESTED**; браузерных
PASS этот генератор не создаёт. Локальная email-ветвь не принимается за
доказательство включённого email-входа на production, а Telegram-ветвь не
означает отправленного сообщения или завершённого входа.

Friends search/requests/invitations/blocking, редактор профиля, содержимое
чужих игр и внешний интерфейс Telegram не сканируются. Никакие запросы или
приглашения не отправляются. У cancelled Tyaga room быстрый realtime-путь
отсутствует: `boundaries.cancelled-tyaga-room` сохраняет точный исходный fallback
и явно оставляет его дальнейшие controls вне этого узкого scope. History
clear/restore — общие кнопки аккаунта с телом POST `{}`, а не скрытый фильтр
по `gameId`; реестр не сужает их действие до одной игры.

После изменения любого включённого portal/auth/registry файла реестр нужно
пересоздать перед общим commit. `--check` сравнивает полный JSON с текущими
исходниками и обнаруживает устаревший снимок; он не заменяет браузерный U65.
