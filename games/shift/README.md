# Сдвиг / Shift

Командная игра Iva Games: пилоты сражаются и доставляют одну батарею, штурманы сдвигают комнаты с находящимися внутри дронами и предметами.

## Запуск

Из корня репозитория:

```bash
npm ci
npm run build:foundation
node games/shift/scripts/demo.mjs --port 4398
```

Точка входа — `http://127.0.0.1:4398/shift`. Демонстрационный стенд использует отдельную SQLite, файловую почту и два настоящих локальных тестовых аккаунта. Telegram и внешняя доставка отключены. Данные запуска и отдельные browser storageState находятся в игнорируемой `.qa/shift-demo/`; они не являются производственными учётными записями и не публикуются.

`--rooms` создаёт обычными API два лобби 2×2 и 3×3. `--start` также подтверждает готовность и запускает их. Без этих флагов состав и старт можно проверить через интерфейс. В существующей платформе `/shift` открывает практику и уроки, а командная игра работает в `/rooms/:id` с действующей авторизацией и друзьями.

## Правила и управление

Полные правила и заданные критерии: [SPEC.md](SPEC.md).

- Пилот: WASD или стрелки — движение, мышь — прицел, левая кнопка или пробел — огонь, E — взять/сбросить батарею, Q — метка команде.
- Штурман: выбрать комнату на плане или стрелками относительно шахты, Enter — подтвердить сдвиг, Esc — отменить выбор, Q — метка комнаты.
- На сенсоре: два стика, отдельные огонь и действие. У штурмана доступны план и кнопка подтверждения.
- Настройки: RU/EN, переназначение, громкость сигналов и фона, чувствительность, масштаб текста, качество, 2D, эффекты и снижение движения.
- Практика и каждый из двух уроков имеют отдельные локальные сохранения. Онлайн восстанавливает серверный матч; управление одной вкладкой защищено эпохой контроллера.

## Код и ресурсы

- `src/core`: детерминированные правила, геометрия, разрешённые виды.
- `src/bots`: политика, принимающая только разрешённый вид места.
- `src/server`: авторитетный runtime и SQLite; игровой адаптер общего `RealtimeGameRuntime`, [контракт игры](src/server/README.md).
- `src/render`: Three.js 2.5D и Canvas 2D из одного разрешённого вида.
- `src/ui`: лобби, уроки, HUD, настройки, звук и результат.
- `scripts/generate-assets.py`: повторяемые оригинальные GLB, SVG и WAV.
- [ASSETS.md](ASSETS.md), [assets-manifest.json](assets-manifest.json): происхождение, лицензии, размеры, хеши и поставка.

Версии: `shift@1`, `shift-content@1`, `shift-wire@1`, `shift-bot@1`. Общая оболочка сообщений — [`iva-live@1`](../../packages/session-kit/REALTIME.md) из PR42, шлюз `/api/platform/v1/rooms/:roomId/live` без query, с обычной сессионной cookie платформы. Сервер не принимает от клиента координаты, попадания, очки или ход времени. Предсказание локального движения меняет только изображение; новая авторитетная проекция пересогласует положение и пространство.

## Проверки

```bash
npm run shift:test
npm run check:platform
npm run check
npm run build:all
npm run platform:smoke
npm run portal:e2e
npm run shift:e2e
node games/shift/scripts/browser-edge-acceptance.mjs --cycle local
node games/shift/scripts/online-browser-acceptance.mjs --cycle 1
```

Для браузерных сценариев нужен установленный Playwright Chromium. Переменная `SHIFT_CHROMIUM_EXECUTABLE` позволяет указать обычный исполняемый файл Chromium/headless-shell. Сервер и браузер запускаются внутри одного harness с отдельными портами, базой и профилями. Команда `shift:e2e -- --ui --lessons --touch` выполняет интерфейс, уроки и сенсорную эмуляцию; без флагов добавляется полная матрица локальных матчей.

`browser-edge-acceptance.mjs` проверяет порог двери, попадание на последнем тике сдачи, ничью, клавиатурное раскрытие сводки и доступность реванша после завершения платформенной комнаты в настоящем собранном интерфейсе. Начальные серверные сохранения и шаги времени в этом изолированном стенде контролируются; это отдельные пограничные проверки, не обычные полные матчи. Параметры `--browser PATH` и `--port 4418` задают его Chromium и порт. Онлайн-матрица по умолчанию выполняет матчи последовательно, каждый с двумя независимыми авторизованными браузерными профилями и ботами.

## Профиль реальной нагрузки

```sh
node games/shift/scripts/runtime-load-profile.mjs --run --source-ref HEAD --port 4428
```

Скрипт поднимает отдельную платформу, шесть обычных 3×3 матчей и шесть Chromium-контекстов, затем измеряет до 60 реальных секунд с неизменным autoTick. `--browser PATH` задаёт установленный Chromium/headless-shell. Не запускайте профиль одновременно с другими тяжёлыми локальными проверками. Раннее завершение матча сохраняется как неполное окно, без ускорения или перезапуска игры. Фактические числа, воспроизводимость, исходные хеши и ограничения — в [QA_LOAD.md](QA_LOAD.md).
